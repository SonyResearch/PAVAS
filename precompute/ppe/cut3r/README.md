# CUT3R

This directory contains the vendored CUT3R-based implementation used for motion
reconstruction and velocity estimation in the PPE stage.

Main files and subtrees:

- `cut3r_vgg_instant_velocity.py`
- `add_ckpt_path.py`
- `viser_utils.py`
- `src/dust3r/`
- `src/croco/`

This code still requires the corresponding Python dependencies and a CUT3R checkpoint.
