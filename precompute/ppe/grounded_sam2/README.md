# Grounded-SAM-2

This directory contains the vendored Grounded-SAM-2-based implementation used for
segmentation and tracking in the PPE stage.

Main files and subtrees:

- `prep_only_manifest.py`
- `Florence2_train_rev.py`
- `sam2/`
- `utils/`

This code still requires the relevant Python dependencies and SAM2 checkpoints.
