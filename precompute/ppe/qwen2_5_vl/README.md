# Qwen2.5-VL

This directory contains the vendored Qwen2.5-VL-based implementation used for:

- moving-object discovery
- mass estimation

Main files:

- `qwen_vlm_bow_moving_slurm.py`
- `_qwen_mass_feature_moving_v2.py`

These scripts still require the corresponding Python dependencies such as `transformers`,
`accelerate`, and `qwen-vl-utils`.
